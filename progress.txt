## Codebase Patterns
- Contracts live in ../koine (KINP/KGP/KCB/KMI/KCS + ADR-0001). Implement against them; do not
  re-specify.
- ADR-0001 invariants: registry routes by lookup (returns addresses, never proxies traffic);
  the console observes REAL direct connections; provider-router (model backends) and
  inter-platform routing are distinct concerns. These are encoded as assertions
  (`describeRegistry().proxiesTraffic === false`), not just prose — don't relax them to make a
  test pass.
- Two toolchains, one gate: `make check` runs everything; `make check-<area>` runs one.
  Deps install themselves. See CLAUDE.md "Quality gates".
- TS is a **source-first** npm workspace: root package.json holds the shared devDeps, each
  package's `exports` points at `src/index.ts`, `tsc` emits nothing — so no cross-package build
  ordering. Relative imports carry the real `.ts`/`.tsx` extension.
- The Python tools read config from `provider-router/pyproject.toml`, so the Makefile runs them
  as `cd provider-router && uv run …`; `uv --project … run mypy` silently loses the config.
- The koine spec versions are pinned in BOTH `schemas/src/versions.ts` and
  `agora_provider_router.KCB_VERSION`, and a pytest cross-asserts them. Bump both together.
- Secrets are `SecretStr` and nothing retains the raw environment — a config that does puts
  every exported key into its own `repr`. Anything reportable goes through a `describe()`
  that reports *whether* a key is set, never its value; tests assert on the rendered surface.
- FastAPI routes take their dependencies as `Annotated[T, Depends(fn)]` module-level aliases
  (a call in an argument default trips ruff B008), and `app.dependency_overrides` keys on the
  `fn` identity — which is how a test swaps the whole router for one it configured.
- **Every router knob goes under `AGORA_*`.** `RouterConfig.env` retains only that prefix (so no
  repr can leak a secret), which means a new variable named that way arrives at the ladder, the
  cost table and the manifest with no plumbing — `AGORA_PRICE_*`, `AGORA_PUBLIC_BASE_URL`.
- **Safety invariants are asserted on what was CONTACTED, not on what won.** `recording_transport`
  records every backend the transport was handed; zero-spend and budget tests assert that list is
  empty. "It lost the race" is not the same guarantee as "it was never dialed".
- **Cross-language pins make file paths API.** The spec versions now live in
  `schemas/src/versions.ts` and the router's zero-spend manifest is captured at
  `registry/src/fixtures/provider-router.manifest.json`; pytest reads BOTH by path. Moving or
  regenerating either is a two-language edit. Regenerate the fixture with the command in the
  test's failure message; never hand-edit it.
- **Unpriced is not free, anywhere in the stack.** The router flags a cost it could not compute,
  and both `find` and `path` rank those last however expensive the priced alternative is. A
  missing price read as 0 makes the unknown route the system's favourite.
- **Under `mypy --strict`, a helper taking `**env: str` plus another parameter needs that
  parameter positional-only** (`def f(calls, ceiling, /, **env: str)`) — the splat could otherwise
  supply it. Splitting into two helpers (conftest's `router_for`) is the other way out.

## US-AG2 — Provider-router: the sacred ladder, OpenAI-compatible, always-completes
- New modules under `provider-router/src/agora_provider_router/`: `ladder.py` (tier order as
  configuration), `backends.py` (tier → dialable backend or the reason it is not),
  `placeholder.py` (the deterministic terminal tier), `router.py` (the walk + the invariant),
  `config.py` (the CUNEIFORM_PROVIDER_* schema); `app.py` grew the OpenAI routes and /doctor.
- Tests: `test_ladder.py`, `test_config.py`, `test_fallthrough.py`, `test_zero_spend.py`,
  `test_app.py` + `conftest.py` (43 passing). Gate `make check-provider-router` green.
- Ported from Analyzer with two deliberate changes: ladder tokens are the four TIERS
  (paid/mlx/local + terminal placeholder) rather than vendor names, because here the router
  *is* the ladder; and the local tiers require a CONFIGURED base URL — no implicit localhost
  probe, or "no local servers" would depend on what happens to be listening on the box.
- Next: US-AG3 — budget ceilings + the KCB manifest. Analyzer's cost logic is in
  `~/Development/analyzer/src/filmstudio/core/cost.py` / `cost_gate.py`. Seams already in place:
  `Backend`/`TierResolution` are where a per-capability `cost` hangs, `Completion.routing()`
  is where projected/actual cost joins the response, and the placeholder already reports
  zero-token usage so an estimator can read every tier the same way.

### Learnings for future iterations
- **A config must not retain the environment.** `RouterConfig` first kept the whole env dict
  for ladder lookups; a `repr` of it then contained every exported key and the secrets test
  caught it. It now keeps only `AGORA_*`. Keys are `SecretStr` everywhere, and failure
  reasons redact the backend's own key (a transport error quotes the URL it dialed).
- **`next(gen)` on a `@contextmanager`-shaped generator is a trap.** `client = next(client_for(r))`
  left no reference to the generator, so it was collected immediately, its `finally` ran, and
  the FastAPI dependency override was cleared before the request — two tests silently
  exercised the real environment instead. Use a plain function + an autouse cleanup fixture.
- **FastAPI + ruff:** `Depends(...)`/`Body(...)` in an argument default trips B008. Use
  `Annotated[Router, Depends(get_router)]` aliases — and keep `Depends(get_router)` by name,
  since that identity is what `app.dependency_overrides` keys on.
- **A test helper taking both `**env` and a named option does not type-check** under
  `mypy --strict`: unpacking a `dict[str, str]` could supply that option. Split them —
  `router_for(**env)` for the common case, `Router(config_for(**env), transport)` when a test
  needs a fake transport.
- Tests import `conftest` directly (`from conftest import ...`); pytest puts `tests/` on the
  path and mypy resolves it, so shared helpers do not need a package.
- The `agora` key on every generation response (tier/provider/model/attempts, mirrored into
  `X-Agora-*`) is the seam the console (US-AG5) reads. Body over header on purpose: a header
  needs CORS expose-headers to survive a browser fetch.

## US-AG3 — Cost/budget enforcement + the router's KCB capability manifest
- New `provider-router/src/agora_provider_router/cost.py` — pure pricing: `measure` (size a
  request per modality), `rate_for` (per-(modality, provider) table + `AGORA_PRICE_*` override),
  `project` (before dispatch) / `settle` (against the response), `take_ceiling`/`parse_ceiling`,
  `within`/`refusal`. New `manifest.py` — the KCB §2 manifest, at `/.well-known/kcb-manifest.json`.
- `router.py`: the walk is budget-gated; `Attempt` gained `dialed`, `Completion` gained
  `projected`/`actual`/`budget_units` and a `cost()` block on `routing()`. `backends.py`:
  `resolve_tier(..., rank)` — `_resolve_paid` collects ALL usable vendors and picks
  `min(ready, key=rank)` when ranking, first-declared otherwise. `app.py`: the
  `X-Agora-Budget-Units` request header, an `X-Agora-Cost-Units` response header, the manifest
  route, and a 422 on an unreadable ceiling.
- Tests: `test_cost.py`, `test_budget.py`, `test_manifest.py` + HTTP coverage in `test_app.py`
  (109 passing). `make check` exit 0.
- **Ladder = preference, ceiling = constraint.** The AC says "prefers the lowest-cost satisfying
  tier", but sorting the whole ladder by cost would send EVERY budgeted request straight to the
  free placeholder and delete the sacred ladder. So rungs are walked in ladder order and one
  projected over budget is pruned; because the ladder runs expensive→free, the first survivor IS
  the best affordable rung. Cheapest-wins applies only where the ladder expresses no preference —
  between two usable paid vendors (`rank`).
- **Costs are KCB budget units, not USD** (anchored 1 unit = US$0.00001): a grant crosses projects
  that share no billing account, so the bus needs one comparable scalar. Rates ported from Analyzer's
  USD table, which is at `~/Development/analyzer/src/filmstudio/cost.py` — NOT `core/`, as US-AG2's
  note said. `unpriced` is deliberately not `free`: an unknown vendor prices 0.0 but is flagged,
  and `within()` refuses it under any ceiling, or it would become the ladder's cheapest route.
- **The manifest advertises the CURRENTLY RESOLVED tier's cost**, so a keyless router publishes
  `tier=placeholder, est_units=0`. A static price list would make the registry's zero-cost
  preference (KCB §3) wrong precisely on zero-spend deployments. Priced against a fixed nominal
  request per modality (`NOMINAL`), published as `cost.basis`, so figures are comparable.
- **No endpoint is advertised that is not served** — no `mcp`/`a2a` keys until they exist, because
  a manifest address is a promise the registry hands to peers who dial it DIRECTLY (ADR-0001
  decision 3). `test_manifest.py` pins the endpoint key set, so a future story must add the server
  and the advertisement together.
- Next: US-AG4 — the registry indexes this manifest. It is served at
  `/.well-known/kcb-manifest.json` and `manifest.capability_manifest()` builds it; the TS side has
  no manifest type yet, so US-AG4 will want one in `schemas/`.

### Learnings for future iterations
- **Assert on "was it dialed", not "did it win".** Spend happens at the connection, so
  `recording_transport`'s `calls` list is the real budget assertion; `completion.tier` alone would
  pass even if the paid rung had been contacted and merely lost.
- The `**env` + named-option mypy trap (US-AG2's note) bites again in test helpers. The fix that
  keeps call sites readable is a **positional-only** parameter:
  `def complete_with(calls, ceiling, /, **env: str)`.
- Derive test constants from the code under test (`PAID_UNITS = project(...).units`), not
  arithmetic on the rate table — `round(rate*qty, 6)` != `rate*qty` in float, and `measure("text")`
  adds prompt chars/3.5 on top of `max_tokens`.
- Editing `tasks/chief/*.json` with `json.dump` reformats the whole file (escapes em-dashes,
  re-wraps arrays). Flip `"passes"` with a surgical string edit instead.

## US-AG4 — Thin discovery registry: route-by-lookup, never proxy
- New `registry/src/`: `registry.ts` (the index + `find`), `path.ts` (capability-path search),
  `ports.ts` (`matchesPort` / `servesWorld` / `satisfies`), `cost.ts` (the ranking),
  `crawl.ts` (pull population + `registerProviderRouter`), `fixtures/` (synthetic providers +
  the router's captured manifest). `schemas/` split into `versions.ts` / `planes.ts` /
  `identity.ts` / `manifest.ts` with `index.ts` re-exporting. `clients/kcb-client` gained
  `addressOf` / `endpointFor` and an open endpoints map. `resolver/` gained the interface stub.
- Tests: 51 in registry, 16 in schemas, 5 each in clients/resolver, +1 pytest. `make check` exit 0.
- **The registry's surface is asserted, not just documented.** `describeRegistry().verbs` is
  compared against the prototype's own method names, so adding an `invoke`/`proxy` method fails
  the gate. Prose saying "never proxies" is what every proxy's README said first.
- **`find` splits into two questions and so does the code.** `matchesPort` (does this port
  answer the query) and `satisfies` (can this produced port feed that consumed port) look
  similar and are not: the second is asymmetric — the consumer states requirements, the
  producer meets the ones stated. Conflating them made path search accept backwards hops.
- **Unpriced is not free** (carried over from US-AG3's `cost.unpriced`). Both `find` and `path`
  rank unpriced last however expensive the alternative; reading a missing price as 0 would make
  the *unknown* route the registry's favourite, which is the opposite of KCB §3 delta K.
  A capability with no `cost` block at all is unpriced too — absence is not zero.
- **Ladder-style preference vs. constraint, again.** Path search is best-first on
  (unpriced hops, projected units, hop count) — not shortest-path — because §3 says "prefers
  zero-cost routes"; a shorter paid path losing to a longer free one is the intent.
- **A world query is refused, not guessed.** A media port with no `world_pattern` does not
  answer `find({world})`. Delta J exists because world-scoped discovery is impossible without
  the declaration; defaulting to "probably all worlds" hands back a provider that may hold
  none of that world's material. But `satisfies` only constrains worlds when BOTH ends declare
  one — mid-chain, an unscoped producer is unscoped material, not wrong-world material.
- The provider-router is the first entry, crawled from `/.well-known/kcb-manifest.json`.
  `registry/src/fixtures/provider-router.manifest.json` is the real zero-spend manifest captured
  verbatim, and `provider-router/tests/test_manifest.py::TestTheRegistryFixture` asserts the
  capture is still current — the same cross-language pin as the KCB version, one level up.
  The failure message carries the regeneration command; regenerate, never hand-edit.
- Next: US-AG5 — the console. Seams in place: `registerProviderRouter(registry, baseUrl, {fetch})`
  takes an injectable fetch (so the console can instrument the traffic it observes),
  `find({capability:'generate.text'})[0].capabilities[0].endpoint` is the exact URL to POST to,
  and the response's `agora` block (US-AG2) carries the tier/cost to surface. `createLocalResolver()`
  is the resolver the console depends on; `describeResolver().implemented === false` on purpose.

### Learnings for future iterations
- **Split a package into modules before it needs re-exporting, not after.** `schemas/index.ts`
  held the spec-version pin that a *pytest* greps by path; moving it to `versions.ts` meant
  editing `test_skeleton.py` in the same commit. Cross-language pins make file paths API.
- **`as const` on a port literal breaks assignability**: `readonly ['audio/wav']` is not
  `string[]`. Annotate test fixtures with their real type (`const MIDI: MediaPort = …`) instead.
- **Avoid a runtime import cycle by extracting the shared leaf.** `path.ts` needed `costOf` from
  `registry.ts`, which imports `path.ts`; `cost.ts` broke it. Type-only imports (`import type
  { Registration }`) are erased and stay fine either way.
- `@typescript-eslint/recommended` bans `!`, so narrow into a local (`const { mediaType } = query`)
  before using an optional field inside a closure — property narrowing does not survive a callback.
- `structuredClone` is not in the `ES2023` lib the repo pins. A manifest is JSON by definition, so
  `JSON.parse(JSON.stringify(x))` is both available and honest about what is being copied.
- Frozen objects: assigning to one throws only in strict mode — which ESM always is, so
  `expect(() => { frozen.x = 1 }).toThrow()` is a valid assertion in vitest.

## US-CS7 — Live fabric monitor: passive, cross-platform event feed
- New `console/src/monitor/`: `monitor.ts` (the passive watch — sources, `sweep()`, `events()`,
  `describeMonitor()`), `feed.ts` (the log projected into filterable `FabricEvent` rows),
  `Monitor.tsx` (the panel). New `console/src/kcs/spans.ts` — the control-plane counterpart to
  `facts.ts`. `Observation.span` + `planeOfFrame` in `kcs/log.ts` / `kcs/link.ts` /
  `kcs/standin.ts`; `observeCommons` in `commons.ts`; a third `monitor` mode in `App.tsx`;
  fixtures `console/src/fixtures/monitor/{analyzer,insimul}.json`.
- Tests: `spans.test.ts` (8), `feed.test.ts` (11), `monitor.test.ts` (15), +5 in `App.test.tsx`.
  `make check` exit 0 (191 console tests).
- **What ADR-0001 lets a passive observer do is the whole design.** Decision 7 permits
  subscribing; it forbids reading the wire between two other peers, because that IS the
  payload-aware proxy. So the data plane is complete today (every delta/media event a producer
  publishes reaches the feed, whoever triggered the work) and the control plane is visible only
  where a provider EMITS a record of its own exchanges. A provider that emits none is absent at
  the invoke level — stated per source on screen, in `describeMonitor().limitation`, and in both
  READMEs. A monitor that quietly showed an empty invoke view would read as "no invocations
  happened" when it means "nobody emitted telemetry".
- **`kcs/spans.ts` is deliberately provisional and narrow.** koine has no emitted-telemetry
  contract (KCB §4 fixes five verbs and nothing about observability), so the recognition rule is
  "a frame is telemetry only when it SAYS it is" (`kind: exchange`, or a `span`/`exchange`
  envelope) and it must name a `verb` or a `capability`. Inferring spans from delta shapes would
  have the monitor reporting exchanges nobody made. This is the one module that expects to be
  rewritten against a spec rather than to define one — the koine follow-up is a KCB observability
  extension fixing the span shape.
- **A span is `control`, not `knowledge`.** `Plane` is the KCB §2.1 *data*-plane vocabulary, so
  `planeOfFrame` returns `undefined` for a telemetry-only frame and the feed types the row
  `control`. Defaulting to `knowledge` (which the old inline expression did) would have filed
  every span under the knowledge plane and made the plane filter lie.
- **The monitor is configured with what to watch, not handed every fixture.** `monitorStandins()`
  is its own small map; subscribing to every bundled fixture with a `subscribe` section would
  watch the same peer three times over, once per scenario that recorded it. `monitor/analyzer.json`
  emits telemetry and `monitor/insimul.json` does not, so the documented limitation is
  demonstrated on screen rather than only asserted in prose.
- **The App keeps the monitor instance, not its snapshot.** The monitor owns the observation log,
  so sweeping again appends and the feed accumulates; storing a snapshot would have "sweep again"
  replace the feed with the last few seconds of it, and `since` would filter against the last
  button press rather than real elapsed observation.

### Learnings for future iterations
- **Encode a topological invariant as an assertion on the code's own surface.** `monitor.test.ts`
  reads `Object.getOwnPropertyNames(FabricMonitor.prototype)` and fails if an `invoke`/`emit`/
  `relay` ever appears — the same shape as `describeRegistry().verbs` (US-AG4). Prose saying
  "passive" is what every proxy's README said first.
- **`worlds_pattern` is not a world.** KCB delta J patterns (`insimul:world:*`) cannot be expanded
  into a subscription target; `worldsIn()` collects concrete `worlds` off knowledge ports only,
  and a peer declaring none is subscribed to without a world filter (KCB §4's other form).
- Fixture map insertion order is the sweep order, and therefore the feed's. A test asserting the
  event sequence is asserting on `MONITORED`'s key order — assert on a `Set` of participants when
  order is not the point.
- `eventsFrom` reads only `direction: 'frame'` entries. That single line is what separates "the
  console's own traffic" (the timeline) from "what crossed the fabric" (the feed); widening it to
  responses would put every manual invoke into the passive feed.
